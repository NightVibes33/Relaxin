box by ASCII — full text transcript

box is the cheapest, most powerful sandbox for agents — built for agent factories. It is a product by ASCII (https://ascii.dev). A box is a persistent Linux (Ubuntu) virtual machine with SSH and SCP access, Docker support inside the VM, a dedicated IPv4 per machine, a 60fps virtual desktop, and fast disk-level forking from a snapshot. It is built for AI agents, for programmatic use, and for humans.

Pre-configured in every box

Docker, VS Code, Chrome, Ghostty, the GitHub CLI, Rust, Node.js, and Bun come pre-installed. Boxes are full Ubuntu machines, so you can run any devtool, language, or workflow. Bring any agent: Claude Code, Codex, or OpenCode.

Why box

  • Designed for agents: a box starts easily via a CLI built for agents, programmatic use, and humans.
  • Ready out of the box: Docker, GitHub CLI, languages, and other devtools are pre-installed.
  • Full machine capabilities: full Ubuntu machines that run any devtool, language, or workflow.

Pricing

Simple, honest pricing. Pay only for the boxes you run, billed by the second, with a $20 minimum per month. $20 buys 2,000,000 VM-seconds (about 555 hours) of dedicated 4 vCPU / 8 GB VM-time, spread across one box or many. Boxes come in three sizes and spend that time at their own rate: small (2 vCPU / 4 GB) at 0.5x, default (4 vCPU / 8 GB) at 1x, large (8 vCPU / 16 GB) at 2x, so a mixed fleet is just the sum of its parts. box is the most affordable option compared with E2B, GitHub Codespaces, Daytona, Modal, Vercel Sandbox, and others — see the full comparison at https://box.ascii.dev/compare.

Install the box CLI

macOS and Linux: curl -fsSL https://ascii.dev/api/box/install | sh

Windows: irm https://ascii.dev/api/box/install.ps1 | iex

Simple API / CLI commands

  • box new — spin up a box
  • box ssh / box scp — SSH/SCP
  • box prompt — run Claude or Codex inside
  • box fork — clone from a snapshot
  • box stop — snapshot and pause billing
  • box desktop — use the virtual desktop at 60fps
  • box list — see all your boxes

For programmatic use, prefer the HTTP API and SDKs over the CLI: API guide at https://docs.ascii.dev/box/api/v1, Python and TypeScript SDKs at https://docs.ascii.dev/box/sdks/overview. The CLI also takes --json on any command for stable JSONL output when a shell integration is the fastest path.

Limits

EU regions today (Germany, Finland, France). Self-serve plans scale from 100 to 1,200 active boxes per account; more by agreement. Default box TTL is 1 hour and is overrideable.

FAQ

Am I billed when a box is stopped?

No. Stopping snapshots the box and pauses billing. Resume any time in a few seconds.

Is the $20/mo a per-box minimum?

No. It is the account total, and it converts into 555 hours of machine time to spend across any number of boxes.

Where do boxes run?

In the EU: Germany, Finland, and France. Your data and snapshots stay there.

What survives stop and resume?

Your files, installed packages, and enabled systemd services. Hand-run processes need a restart.

Can I give boxes to my own users?

Yes. Create them no-env so they receive none of your account's secrets and stay confined to themselves.
